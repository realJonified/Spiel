# Hüpfi springt

Ein kleines Jump-and-Run im Browser – eine einzige Datei, keine Installation.

**Spielen:** `index.html` im Browser öffnen.

## Steuerung

| Aktion   | Tastatur                 | Handy                  |
|----------|--------------------------|------------------------|
| Laufen   | ← / → oder A / D         | Knöpfe links unten     |
| Springen | Leertaste, ↑ oder W      | Knopf rechts unten     |
| Pause    | P                        | –                      |

Länger gedrückt halten = höher springen.

## Regeln

- 3 Welten (Wiese, Abendrot, Nacht), am Ende jeder Welt wartet die Fahne.
- Münzen geben 10 Punkte, alle 50 Münzen gibt es ein Extraleben.
- Auf Gegner springen gibt 100 Punkte – seitlich berühren kostet ein Leben.
- Stacheln und Abgründe meiden.
- Je höher du die Fahne berührst, desto mehr Bonuspunkte.
